# 前端页面设计与代码框架文档

> 版本：V1.0 | 日期：2026-07-16 | 技术栈：Vue 3 + Vite + Vue Router + Axios

## 一、为什么不用 Streamlit

| Streamlit 短板 | 影响 |
|---------------|------|
| st.session_state 模拟路由 | 无真正的页面跳转，浏览器前进/后退失效 |
| 无原生 Tab/Modal 组件 | 全景稽核 4 维度只能折叠面板凑合 |
| st.rerun() 全页刷新 | 大数据表格每次重载，卡顿明显 |
| 单文件脚本膨胀 | 当前 streamlit_v3.py 已 500+ 行，维护困难 |

## 二、技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 框架 | Vue 3 (Composition API) | 组件化，状态管理清晰 |
| 构建 | Vite | 秒级热更新 |
| 路由 | Vue Router 4 | 三路由，支持参数传递 |
| HTTP | Axios | 封装 FastAPI 调用 |
| UI | 原生 CSS | 轻量，审计行业不需要花哨 |
| 表格 | 原生 table + CSS | 大数据量表格展示 |

## 三、路由设计

`
/                        → Workbench.vue     主工作台
/review/:runId           → Review.vue        方案审批
/results/:runId          → Results.vue       执行结果
/results/:runId?tab=match   → 匹配结果
/results/:runId?tab=audit   → 全景稽核
/results/:runId?tab=format  → 格式规范
`

## 五、页面布局

### 5.1 主工作台 Workbench.vue

三栏布局：左(上传+指令) | 中(Run列表) | 右(RAG问答)

关键交互：
- 点击 Run 行 查看详情 → router.push('/results/' + runId)
- PENDING_REVIEW 审阅方案 → router.push('/review/' + runId)
- 上传+提交 API调用 → RunList刷新

### 5.2 方案审批 Review.vue

内容：顶部返回按钮 + Run ID、平台提案说明(match_explanation)、策略总览卡片(4个指标)、筛选条件+匹配策略+汇总维度、算子参数折叠、修改意见文本框、确认执行/重新编译按钮

### 5.3 执行结果 Results.vue

三个 Tab：
- Tab匹配结果: 指标卡片 + 数据表格 + 调整规则重跑
- Tab全景稽核: 按严重度分组的问题清单卡片
- Tab格式规范: 一键格式规范化按钮

## 六、API 封装

```
// api/index.js
import axios from "axios"

const api = axios.create({
  baseURL: import.meta.env.VITE_API_BASE || "http://localhost:8000/api/v3",
  timeout: 180000,
})

api.interceptors.response.use(
  res => res.data,
  err => {
    console.error("[API Error]", err.response?.data?.detail || err.message)
    return Promise.reject(err)
  }
)

export default {
  createRun(formData)    { return api.post("/runs", formData) },
  listRuns()             { return api.get("/runs") },
  getRun(runId)          { return api.get(`/runs/${runId}`) },
  executeRun(runId)      { return api.post(`/runs/${runId}/execute`) },
  ragSearch(query)       { return api.post("/rag/search", { query, top_k: 5 }) },
}
```

## 七、组件通信

```
App.vue
├── Workbench.vue
│   ├── FileUpload.vue  → emit("files-changed", files)
│   ├── IntentInput.vue → emit("submit", {intent, files})
│   └── RunList.vue     → emit("view-detail", runId)
├── Review.vue
│   ├── StrategyCard.vue (props: dagJson)
│   └── emit("confirm") | emit("recompile")
└── Results.vue
    ├── MatchTab.vue (emit: "retry", params)
    ├── AuditTab.vue (props: findings)
    └── FormatTab.vue (emit: "format-apply")
```
